首次安装一次固定加载器，之后插件升级只更新独立版本目录，无需重新修改、复制或签名整个 ZCode 应用包。

- 下载并解压 `ZCode-Music-Installer-0.3.0-macOS.zip`，退出 ZCode 后双击安装器，选择「安装 / 修复」。
- 安装器同时支持 Apple Silicon 和 Intel，使用已安装 ZCode 的运行时，无需另外安装 Node.js 或编译工具。
- 歌词设置新增版本、检查更新、更新并重启、回退并重启。
- 升级包使用 Ed25519 签名与逐文件 SHA-256 校验，原子切换并保留上一版本；失败保留现有版本。
- 保留主题色 / 专辑色、歌名和数字进度配色、灰色未播放进度条，以及现有逐字歌词功能。

适配 ZCode macOS 3.15.3。ZCode 官方升级可能移除加载器，需要安装器重新检查适配并修复。

从 0.2.x 迁移需要第一次安装时的官方原包备份 `backup/ZCode.app`；安装器会在需要时提示选择。新版会把备份保存在固定目录，之后无需保留源码文件夹。

此安装器使用临时签名，未使用 Apple Developer ID 公证。若 macOS 阻止运行，请自行确认来源并按系统提示允许；不要关闭 Gatekeeper。插件升级签名与 Apple 公证是不同机制。
