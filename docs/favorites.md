# 我喜欢

从 0.3.15 起，悬停歌词条会在「上一首」左侧显示红心。空心表示未收藏，红色实心表示已加入设置面板内登录账号的「我喜欢」。再次点击取消喜欢。未登录时点击打开登录面板；插件账号独立于 QQ 音乐桌面客户端。

点击立即更新红心，保存期间禁止重复操作，失败则恢复之前的显示并在设置面板提示。请求超时不能确认服务端结果时，下一次点击先重新读取状态，再允许操作。歌曲未能准确匹配、演示歌曲或系统上报来自其它播放器时禁用按钮，避免收藏同名的其它版本。准确匹配要求标题版本与歌手相符，并对已知专辑和时长作硬校验；与封面、歌词共用 [统一歌曲身份](song-matching.md)。

主进程读取 `music.srfDissInfo.DissInfo.CgiGetDiss`，使用 `dirid:201`、`enc_host_uin`，逐页读取歌曲的 mid/id；默认每页请求 300 首，支持服务端缩小每页数量。集合在内存缓存 10 分钟，写入成功后增量维护。无法完整读取、重复页或不能识别的返回结构均显示状态错误，不把未知状态当成未收藏。超过 30,000 首时停止读取并提示。

写入调用 `music.musicasset.PlaylistDetailWrite.AddSonglist/DelSonglist`，参数为 `dirId:201, tid:0, bFmtUtf8:true, v_songInfo:[{songId,songType}]`。鉴权使用扫码会话的 Cookie 与 musickey 派生的双 GTK 字段。微信会话必须具有加密账号标识；失败不自动退出登录，可重新扫码恢复会话。写请求不自动重试，避免超时后的重复操作。

界面只接收歌曲收藏状态和随机账号修订标识，不接收鉴权材料。主进程验证调用来源与当前歌曲，歌曲 ID 来自主进程核验过的统一身份；退出或切换账号时清空缓存并中止旧请求，旧账号修订标识不能写入新账号。客户端本地歌曲库只提供歌曲身份，不提供收藏状态；它可能保留多个账号的历史数据，不能把其中的“我喜欢”套用到插件独立登录的账号。没有新增加载器 IPC 通道，沿用兼容的 `configure` 桥。

协议参考 [dsh-music-player](https://github.com/kendu76/dsh-music-player)（MIT）；授权声明见 `plugin/lib/qq-gateway.js`。测试覆盖分页、协议字段、错误、缓存、账号切换、并发、过期响应和界面回滚。`preview.html?favorite=liked` 可查看模拟已喜欢状态，`favorite=error` 模拟保存失败，`favorite=logged-out` 模拟未登录；预览脚本不会打包到插件。
