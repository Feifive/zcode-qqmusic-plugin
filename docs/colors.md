# 专辑配色说明

设置提供两种配色来源：ZCode 主题色和专辑色。歌名、歌手、数字进度、歌词高亮和播放控制按钮使用同一强调色，已喜欢的红心固定为红色；进度条未播放部分固定为灰色。

歌名前显示 20×20 圆角封面，使用 40×40 PNG 缩略图以兼顾高分辨率屏幕。封面显示独立于配色选项，两种模式都可显示；无可用封面时使用唱片占位图；关闭“显示专辑封面”后左侧完全隐藏封面区域。悬停约 2 秒后在上方显示原尺寸封面，空间不足时等比缩小。移出、切歌、关闭封面或上翻聊天时关闭大图。封面与配色共用专辑缓存，界面仅接收本地生成的 PNG 数据，不直接请求远程图片。

## 封面配色

1. 主进程通过已有 Perl/dylib 助手，将下载的封面字节送入 ImageIO `CGImageSourceCreateThumbnailAtIndex`：从原图生成缩略、最大边 10 像素并应用方向变换。方形专辑封面得到 10×10 像素。随后只在同尺寸位图中规范成 RGBA8、预乘透明度，不进行第二次缩放。全尺寸预览与 40×40 显示封面继续由 Electron 生成，不参与取色。
2. 亮度低于 12% 或饱和度不高于 11% 的像素按相对亮度分组；相对亮度分界为 0.5。
3. 彩色像素按 8 个色相区间分组，边界为 21、41、76、156、191、257、296、330 度。
4. 按像素数量选取最多 3 个颜色组，在各组内选择最接近 S=0.6、B=0.6 的像素。
5. 饱和度和亮度分别按 `x × 0.2 + 0.5` 调整，然后查询固定配色表。

缩略任务异步运行，按专辑复用现有缓存；跨专辑任务串行执行，避免快速切歌启动过多进程。输入最多 2 MiB、源图单边最多 4096 像素，子进程超时 3 秒，输出最多 8 KiB。原生解码失败使用统一 QQ 绿回退，不再转用盒式平均或 Skia 缩略。

[Apple 的 ImageIO 文档](https://developer.apple.com/documentation/imageio/kcgimagesourcecreatethumbnailfromimagealways)说明了从原图生成缩略及最大像素尺寸选项。这里直接调用系统缩略 API，而不是用另一个重采样器近似。

## 配色表

亮色和暗色主题各有 26 条规则，支持闭区间、无序边界、`or` / `and` 组合以及首条命中。色相 0 按 360 度匹配。歌曲页配色只使用有效的 `magicColors`，不使用 `pureColor` 兜底；`pureColor` 保留供背景渐变使用。纯黑白等没有有效魔法色的封面直接回退 QQ 绿 `#00F168`，不进入灰度规则。

规则数据见 [color-rules.js](../plugin/lib/color-rules.js)，固定测试数据见 [color-rules.json](../test/fixtures/color-rules.json)。并行五色组合保留独立的色相边界与自定义颜色优先级。

## 失败处理

专辑色模式在封面等待、缺失、下载失败、解码失败、无有效像素、取色失败或配色规则无法产生有效结果时，直接使用 QQ 绿 `#00F168`，失败数据不进入灰度规则。重试与缓存按专辑分别管理，避免上一首歌曲的结果影响当前歌曲。

主题色模式始终跟随 ZCode 强调色，不受封面状态影响。

## 验证

`test/colors.test.mjs` 校验完整配色数据、区间边界、取色规则与失败处理。`test/colors.html` 检查实际界面的亮暗配色、QQ 绿兜底与主题色切换。

`test/resampling.test.mjs` 校验异步解码、进程边界、输出校验、串行队列及错误回退；盒式平均只保留作实验对照，不再用于产品取色。`test/native-artwork.test.mjs` 在 macOS 上编译真实发布助手，验证两张封面的输出与 `sips -s format png -Z 10` 逐字节一致，同时覆盖透明度、非方形封面、非法数据及尺寸限制。Linux 上仍可使用冻结的 RGBA 缩略样本验证提取与配色。

`test/fixtures/artwork.json` 记录下载源、文件哈希、系统缩略像素与期望结果。当前样本在 macOS 27.0.1 验证：

| 封面 | 专辑 ID | 系统缩略主色相 | 亮色强调色 |
|---|---|---|---|
| 《晴天》／《叶惠美》 | `000MkMni19ClKG` | 185.45° | `#2DBADE` |
| 《一棵会开花的树》／《谢春花作品选集 (2015)》，2:56 原版 | `001Qp10A3tDOIX` | 177.39° | `#45C8B8` |

“树”样本已用正在播放的歌曲信息核对：`一棵会开花的树`、`谢春花`、`谢春花作品选集 (2015)`、176 秒；固定歌曲 `songmid=000CUTL63LNV46`、`songid=105392885`，封面文件与专辑 ID 一并保存。

原版“树”封面的 100 个像素中有 78 个无彩色，青桶 11、绿桶 5。《晴天》与“树”体现了缩略微差引起桶计数翻转的风险。盒式平均在《晴天》碰巧得到相同强调色，并不能证明它等价于系统缩略；此前把它作为通用修复的结论已撤回。

`test/decode-check.html` 可并排查看冻结的系统缩略参考、浏览器单步缩略和盒式平均，显示各自的桶计数与代表色相。这是重采样差异的诊断页，生产路径以原生助手为准。相同系统 API 不代表不同 macOS 版本之间逐字节恒定，升级系统后应继续运行原生对照测试。
